# Fantasy Armor x Iron's Spells Integration
Minecraft 1.21.1 / NeoForge 21.1.206+ / Fantasy Armor 1.2.4 / Iron's Spells 3.16.3

29セットにIron's Spellsのセットボーナスを追加し、防具ツールチップに日本語で効果と現在の装備数を表示するJavaアドオンです。

## Build
Java 21が必要です。`gradlew build`。GitHubへアップロードした場合は同梱のActionsでもビルドできます。

`libs/` 内の2つのMOD JARはコンパイル用です。配布時は著作権・ライセンスに従い、ソースZIPから除外して各MODを別途用意してください。
